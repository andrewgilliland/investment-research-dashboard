## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues and should be managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The canonical triage labels are used as-is: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository using root `CONTEXT.md` and `docs/adr/` when those documents exist. See `docs/agents/domain.md`.
